Q.写出以下代码的输出结果，并解释原因。
```c
int x = 10;
int* p = &x;
*p = 20;

int arr[3] = {3, 6, 9};
int *q = arr;
int y = ++*arr  +  *++q;

printf("%d %d", x, y);
```
A.20 10 
原因：
（1）定义x 指针p指向x 获得了x地址 能够修改x的值 解引用p即对p所指向的地址的值修改 最终修改为20
（2）定义长度为3的数组 指针q指向数组第一个 即arr[0] *和++均为单目运算符 自右往左看 并且++在变量前面 先算后用 即对arr[0]解引用 取到值为3 而后加一得4 右边则是对q指向得地址+1 则为*(arr+1)
即现在指向了arr[1] 即6 4+6得10
